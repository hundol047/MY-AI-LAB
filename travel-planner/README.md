# 오늘강원

조건 5개만 고르거나 한 줄로 말하면, 영업시간·휴무·이동시간이 맞는 강원도 여행 일정과 숙소를 추천하는 서비스.

## 기존 서비스와 다른 점

| 기존 앱·AI 일정의 문제 | 오늘강원 |
|---|---|
| AI가 없는 장소, 문 닫은 곳, 운영시간 밖 방문을 추천 | AI는 요청을 **조건으로 해석만** 하고, 장소 선택과 시간 계산은 검증된 데이터 기반 엔진이 한다. 충돌 건수를 화면에 표시한다 |
| 입장 마감·브레이크타임 무시 | 계절별 운영시간, 입장·주문 마감, 브레이크타임, 요일별 단축 영업, 매월 휴무일(예: 환선굴 18일), n번째 요일 휴무, 기간 휴장까지 반영 |
| 동선이 비효율적이고 이동시간이 비현실적 | 하루 중심 지역을 먼저 정하고 가까운 순으로 배치. 지도에 실제 도로 경로(OSRM)를 그리고 자동차 이동은 실제 도로 소요시간으로 다시 계산 |
| 축제 정보가 따로 놀음 | 여행 날짜에 열리는 강원 축제를 보여주고, 날짜가 확정된 같은 권역 축제는 일정에 자동으로 넣음 |
| 숙소는 다른 앱에서 따로 | 여행 동선 전체에 맞는 숙소 **한 곳**을 추천해 몇 박이든 짐을 옮기지 않게 하고, 둘째 날부터는 그 숙소에서 출발하도록 일정을 짬 |
| AI가 말만 하고 확인은 안 함 | AI 가이드는 앱 데이터에 있는 장소 id만 고를 수 있고(스키마로 강제), 요청한 변경은 엔진이 영업시간을 다시 확인한 뒤 반영. 못 넣은 곳은 이유와 함께 알려줌 |
| 한 번 만든 일정은 고치기 어려움 | 장소별 `바꾸기`(앞 일정은 유지), 빠른 조정 4개, 한 줄 요청 |
| 입력할 게 많음 | 선택 5개(어디로, 언제, 누구와, 좋아하는 것, 이동). 각 선택지도 5개 이하, 기본값으로 바로 생성 |
| 날씨 반영 없음 | 예보 범위 안이면 비 오는 날을 실내 위주로 자동 변경 |
| 오프라인·내보내기 유료 | 무료로 오프라인 열람(PWA), 링크 공유, 캘린더(.ics), 카카오맵 길찾기 |

## 폰에서 쓰기 (GitHub Pages)

서버 없이 파일만 올려도 일정 만들기·사진·지도·영문·오프라인이 동작한다(AI는 간단 모드, 가게 등록은 숨김).
1. GitHub 저장소 Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: 이 브랜치(또는 main) / **(root)** → Save
2. 1~2분 뒤 `https://hundol047.github.io/MY-AI-LAB/` 로 접속하면 앱으로 이동한다 (저장소 첫 `index.html`이 `travel-planner/public/`으로 보냄)
3. 폰에 설치: 안드로이드 크롬은 메뉴(⋮) → **앱 설치/홈 화면에 추가**, 아이폰 사파리는 공유 → **홈 화면에 추가**

AI·가게 등록까지 쓰려면 Node를 실행할 수 있는 호스팅(Render, Railway, Fly.io 등)에서 `npm start`로 띄운다.

## 안드로이드 앱 (APK)

`android/`의 작은 안드로이드 앱이 앱 파일(`public/`) 전체를 APK 안에 넣고 웹뷰로 연다. 웹 주소 없이도, 인터넷이 없어도 열리고, 지도·사진·날씨만 인터넷을 쓴다. 서버가 없으므로 AI는 간단 모드, 가게 등록은 숨겨진다. 앱 밖 주소(카카오맵·네이버 길찾기)는 휴대폰의 해당 앱·브라우저로 연다. 캘린더 파일 저장은 앱에서는 되지 않는다.
- 다운로드(항상 최신): `https://github.com/hundol047/MY-AI-LAB/releases/download/android-latest/ohneul-gangwon.apk`
- 만들기: `.github/workflows/android-apk.yml`이 앱·안드로이드 코드가 바뀌어 push될 때 GitHub 러너의 안드로이드 SDK로 `android/build.sh`를 돌려(Gradle 없이 javac → d8 → aapt2 → zipalign → apksigner) 릴리스 `android-latest`에 올린다. 직접 만들려면 `ANDROID_HOME=SDK경로 bash android/build.sh`
- 서명 키: 저장소 Secrets에 `ANDROID_KEYSTORE_B64`·`ANDROID_KEYSTORE_PASS`가 없으면 빌드마다 새 키로 서명한다. 이 경우 새 버전을 설치하려면 기존 앱을 지우고 설치해야 한다. 키는 공개 저장소에 넣지 않는다.
- 설치: 폰에서 파일을 받아 열고, 처음 한 번 "출처를 알 수 없는 앱 설치"를 허용한다.

## AI 기능 (OpenAI 호환 API)

- **한 줄로 시작**: "이번 주말 부모님이랑 속초 1박, 차로" → 5개 선택값을 채우고 바로 일정 생성 (`/api/start`)
- **AI 가이드**: 일정을 보며 묻고 고치기. "비 오면 어떡해?", "2일차에 바다 한 곳 더 넣어줘" → 답변 + 일정 변경 (`/api/guide`)
- AI는 말을 이해하고 설명만 한다. 장소는 검증된 데이터의 id 목록 안에서만 고를 수 있고, 배치와 영업시간 확인은 일정 엔진이 다시 한다
- API 키가 없으면 규칙 기반으로 대신 처리한다 (`public/ai-local.js`)

## 추가 기능

| 기능 | 하는 일 |
|---|---|
| 강원 혜택 내비 | 일정에 들어간 장소의 입장료 상품권 환급(소양강 스카이워크, 한탄강 주상절리길, 횡성호수길)을 자동으로 찾고, 기간·지역이 맞는 지원 사업(반값여행 등)의 신청 순서와 필요한 증빙을 보여 준다. 영수증·입장권 사진을 찍어 증빙 보관함에 모은다(이 기기에만 저장) |
| 1박 전환·밤 코스 | 당일치기 일정에 하룻밤을 더하면 늘어나는 장소, 밤 코스, 다음 날 축제, 숙소, 받을 수 있는 혜택을 비교하고 한 번에 1박 2일로 바꾼다 |
| 숙소 안심 체크 | 예약하려는 숙소 페이지의 가격·취소 규정·후기를 붙여넣으면 환불 위험, 추가 요금, 후기 속 위험, 물어볼 것을 쉬운 말로 요약한다 (AI, 키가 없으면 문구 규칙으로) |
| 특산물 재주문 | 여행 중 먹은 음식으로 집에서 주문할 특산물을 정리하고 강원더몰로 연결한다. 다음에 앱을 열면 지난 여행 특산물을 다시 알려 준다 |
| 사진 한 장 가게 등록 | 사장님이 메뉴판을 찍으면 AI가 메뉴·가격을 읽고 영어·일본어·중국어로 번역한다. 사장님이 확인·수정 후 등록하면 다국어 QR 메뉴가 생기고, 여행자 일정 화면의 "사장님이 직접 등록한 가게"에 나온다 (`owner.html`) |

## 범위

- 권역 5곳: 강릉·동해(삼척 포함), 속초·양양(고성·인제 포함), 춘천·철원(화천 포함), 평창·정선(영월·태백 포함), 원주(횡성 포함)
- 장소 100여 곳, 숙소 지역 26곳, 축제 22개(날짜 확정 3개, 매년 열리지만 올해 날짜 발표 전 19개)
- 2박 이상이면 이웃 권역까지 넓혀 일정을 짠다

## 실행

```bash
cd travel-planner
npm install
AI_API_KEY=발급키 AI_MODEL=모델ID TOUR_API_KEY=공공데이터포털_Decoding키 npm start
```

`http://localhost:8080` 접속. 키가 없어도 동작한다(AI 기능은 규칙 기반으로 대체).

| 환경변수 | 필요한 곳 | 설명 |
|---|---|---|
| `AI_API_KEY` | AI 4개 기능 | AI 제공사 API 키 (`OPENAI_API_KEY`도 인식) |
| `AI_MODEL` | AI 4개 기능 | 제공사 콘솔에 적힌 모델 ID 그대로 |
| `AI_BASE_URL` | OpenAI가 아닌 제공사 | OpenAI 호환 API 주소 (예: `https://제공사주소/v1`). OpenAI면 비워 둔다 |
| `AI_REASONING_EFFORT` | 선택 | 추론 모델이면 `low`/`medium`/`high` (응답 속도에는 `low`) |
| `TOUR_API_KEY` | 장소 사진·영문 이름 | 공공데이터포털 한국관광공사 국문(KorService2)·영문(EngService2) 관광정보 서비스 인증키 (Decoding) |
| `KAKAO_REST_KEY` | 좌표 확인 스크립트 (선택) | 카카오 개발자 REST API 키. 없으면 `VWORLD_KEY` 또는 `TOUR_API_KEY`로 확인한다 |
| `VWORLD_KEY` | 좌표 확인 스크립트 (선택) | 브이월드 오픈 API 인증키 (무료). 해외 IP에서는 막혀 있어 한국 안의 컴퓨터에서 실행 |

- 메뉴판 읽기는 이미지 입력을 지원하는 모델이어야 한다.
- 구조화 출력(json_schema)을 지원하지 않는 호환 API면 자동으로 JSON 모드로 다시 요청하고, 서버가 응답 형식을 한 번 더 검사한다. 앱 데이터에 없는 장소 id는 버린다.

## 사진

사진은 한국관광공사 TourAPI 국문 관광정보(KorService2)의 대표 사진(`firstimage`)을 쓴다. **맞는 곳의 사진인지 확인한 것만** `public/photos.json`({장소 id: 주소})에 넣는다.

- 이름 검색(`searchKeyword2`, 해변↔해수욕장·지점명 뺀 이름 등 변형 포함) + 주변 2km 목록(`locationBasedList2`)에서 후보를 모은다
- **좌표 2km 안 + 이름 대응**만 통과: 지역명·띄어쓰기를 빼고 비교, 앞에 지역명이 더 붙은 것("도째비골 해랑전망대")은 같은 곳, 뒤에 다른 말이 붙은 것("고석정 꽃밭", "남이섬 노래박물관")은 옆의 다른 시설로 보고 버린다
- 시장·식당가처럼 여러 가게가 모인 곳(`multi`)은 그 시장·거리 자체로 등록된 결과만 쓴다 (개별 가게 사진 금지)
- 이미지 주소는 https로 바꾸고 실제로 열리는지 확인한다 (`tong.visitkorea.or.kr`)
- 매칭된 관광공사 제목·거리, 버린 후보와 이유, 못 찾은 곳은 [`reports/photos.md`](reports/photos.md)에 남는다. 틀린 매칭을 발견하면 `scripts/bake-photos.mjs`의 `REJECT`에 contentid를 넣고 다시 돌린다

```bash
TOUR_API_KEY=Decoding키 node scripts/bake-photos.mjs     # → public/photos.json, reports/photos.md
```

사진 출처 순서: 대표사진 → 같은 항목의 추가 사진(`detailImage2`, 포스터 제외) → 사람이 검토해 `data.js`의 `photoAt`에 적은 **지역 사진**(자체 등록이 없는 식당가는 그 거리가 있는 항구·역·시장). 다른 카드와 같은 사진이면 다른 컷을 쓰고, 리포트의 "사진" 칸에 어느 방법인지 적는다. 사진이 없는 곳: 보헤미안 박이추커피공장, 태백 한우 실비 거리(관광공사에 사진 없음 — 인터넷 사진은 저작권 때문에 쓰지 않는다). 직접 찍었거나 사용 허락을 받은 사진은 `public/img/`에 넣고 `scripts/photos-manual.json`에 적으면 쓰인다(관광공사 사진이 우선).

화면은 ① `photos.json` → ② `/api/photo`(서버에 키가 있으면 같은 규칙으로 찾기) → ③ 장소에 지정된 위키백과 문서 사진(여러 가게가 모인 곳 제외) 순으로 쓴다. 첫 화면 히어로는 **오늘의 강원**: `photos.json` 중 풍경으로 보기 좋은 41곳(큰 간판·조형물·실내·저화질 제외, `app.js`의 `HERO_IDS`)에서 하루 한 장씩 바뀐다. 한국 시간 자정에 바뀌고 같은 날엔 누구에게나 같은 사진이며, 비슷한 바다가 이어지지 않게 고정된 순서로 섞어 돌린다. 사진은 다 받은 뒤 서서히 나타나고, 오른쪽 위에 "오늘의 강원 · 장소 이름"(EN이면 영문 이름)이 붙는다. 사진이 없는 곳은 분류 색 카드로 보인다.

## 영문 (외국인용)

오른쪽 위 `한국어 / EN` 버튼으로 바꾼다. 선택은 이 기기에 기억하고, 처음 방문하면 브라우저 언어가 한국어가 아닐 때 EN으로 연다.

- 관광공사 영문이 없는 곳은 `scripts/en-manual.json`의 **앱 번역**으로 채운다: 이름은 표준 로마자 표기 + 영어 일반명(Beach, Market, Port…), 소개는 `data.js` 한국어 설명을 옮긴 것(새 내용 없음). `data-en.json`에 `nameSrc`/`descSrc: "app"`으로 표시해 공식 영문과 구분하고, 관광공사 영문이 생기면 그쪽이 우선한다. 지금은 129곳 모두 영문 이름·소개가 있다.
- 장소 이름·소개: 한국관광공사 영문 관광정보(EngService2) → `public/data-en.json`({id: {name, desc}}). 영문 제목 괄호 속 한국어 원명(예: `Gangneung Gyeongpo Beach (강릉 경포해수욕장)`)이 우리 이름과 대응하고 좌표가 2km 안인 것만 쓴다. 소개는 `detailCommon2` 개요의 **첫 문장 그대로**(요약·창작 없음, 200자 넘거나 그곳 이름이 없는 문장이면 생략). 영문 데이터가 없는 곳은 한국어 이름·설명 그대로 보인다. 근거는 [`reports/english.md`](reports/english.md)
- 화면 고정 문구(선택 항목, 버튼, 탭, 운영시간 "Open/last entry/break/Always open/Varies by shop", 축제·숙소·혜택·1박 카드, 알림)는 `public/i18n.js` 한 곳에 모았다. 한국어 원문이 키라 사전에 없는 문구는 한국어로 남는다
- 일정 엔진과 선택 항목(5개, 각 5개 이하)은 언어와 무관하게 그대로다
- AI가 연결되어 있으면 EN 화면에서는 AI 답변도 영어로 받는다. AI 없이 쓰는 간단 모드의 답변·한 줄 시작 해석은 한국어 기준이다

```bash
TOUR_API_KEY=Decoding키 node scripts/bake-english.mjs    # → public/data-en.json, reports/english.md
```

두 스크립트는 응답을 `.cache/tour/`(git 제외)에 저장해 다시 돌려도 API를 다시 부르지 않는다. 새로 받으려면 폴더를 지운다.

## 속도

- 외부 요청(사진·날씨·도로 경로·AI)에는 모두 시간 제한이 있어, 응답이 늦어도 화면은 기다리지 않는다 (사진 3.5초, 날씨 4초, 경로 5초, AI 시작 12초·가이드 20초 뒤 규칙 기반으로 대체)
- 사진은 화면에 보이는 카드만, 동시에 4개까지 불러온다. 미리 모은 사진이 없어 찾아본 곳은 결과를 기억하고, 못 찾은 곳은 하루 동안 다시 찾지 않는다
- 서비스 워커: 앱 파일은 캐시에서 바로 띄우고 뒤에서 갱신, 지도 타일·사진은 한 번 받으면 캐시
- 서버: 텍스트 파일 gzip 압축, 라이브러리·글꼴은 30일 캐시
- AI 가이드: 장소 데이터를 프롬프트 캐시에 두고 effort low로 응답 시간 단축
- 외부 서비스가 8초씩 늦게 응답하는 상황에서도 첫 화면 0.5초, 일정 표시 0.2초 (Playwright 측정)

## 시연 전 확인할 것

- **좌표 확인**: 장소·축제 좌표를 외부 자료와 비교해 1km 넘게 어긋난 곳을 찾는다. 키가 따로 필요 없게, 사진·영문과 같은 **한국관광공사 TourAPI 키(`TOUR_API_KEY`, 무료)**를 기본으로 쓴다. 이름 대조 규칙을 통과한 강원 지역 결과만 비교하고, 지점이 다른 가게(예: 사천점 ↔ 본점)는 버린다.
  ```bash
  TOUR_API_KEY=Decoding키 node scripts/check-coords.mjs                              # 확인만
  TOUR_API_KEY=Decoding키 node scripts/check-coords.mjs --write --only=id1,id2        # 눈으로 확인한 곳만 고치기
  ```
  자동으로 다 고치지 말고 `--only`로 고른다. 긴 해변·탐방로는 기준점이 달라 1km 넘게 차이 날 수 있다 (탐방로는 `trailKm`만큼 허용). 관광공사에 없는 작은 가게는 "결과 없음"으로 남는다.
  관광공사에 없는 곳까지 보려면 브이월드(국토교통부 공간정보 오픈플랫폼, 무료) 키를 `VWORLD_KEY`로 넣는다. 브이월드는 해외 IP 접속이 막혀 있는 경우가 많아 클라우드 환경에서는 연결되지 않으므로(2026년 11월 확인), **한국 안의 컴퓨터에서** `VWORLD_KEY=키 TOUR_API_KEY=키 node scripts/check-coords.mjs`로 실행한다. 연결되지 않으면 자동으로 관광공사로 확인한다. 키를 특정 서비스 URL로 발급받았다면 `VWORLD_DOMAIN`에 그 URL을 넣는다.
  출처 우선순위: `KAKAO_REST_KEY` → `VWORLD_KEY` → `TOUR_API_KEY` → 오픈스트리트맵 검색(느리고 한국 장소 정확도 낮음). 화면의 `길찾기`는 카카오맵 장소 검색으로 연결되므로 좌표가 조금 어긋나도 실제 위치로 안내된다.
  2026년 11월 점검으로 고친 곳: 철원 노동당사, 반계리 은행나무(축제 포함), 강릉솔향수목원, 삼탄아트마인, 한반도지형 전망대, 직탕폭포, 횡성호수길(유료 5구간 입구), 원대리 자작나무숲(진입로 주차장), 화천 붕어섬, 발왕산 관광케이블카, 황지연못, 테라로사 커피공장, 낙산해변, 사천해변, 가시연습지, 하조대(해수욕장이 아니라 정자·등대가 있는 곶), 소금산 그랜드밸리·간현유원지·간현관광지 식당가(간현관광지 매표소 입구, 간현유원지는 간현관광지의 옛 이름). 그대로 둔 곳: 바다부채길(정동 매표소, 탐방로 반대쪽 끝), 한탄강 주상절리길(잔도 반대쪽 입구), 보헤미안 박이추커피 사천점(관광공사에는 본점만 있음). 관광공사 이름 검색으로 바로 안 나오던 32곳은 바뀐 이름(삼양목장→삼양라운드힐, 통일전망대→통일전망타워, 낭만시장=춘천 중앙시장 등), 영문 서비스, 같은 거리에 등록된 식당들의 좌표로 다시 대조했다. 그 결과 고성 통일전망대(9km), 용대리 황태구이 마을(인제 황태마을, 7.8km), 대관령 삼양목장(2.2km), 카페 감자밭(1.3km), 춘천 막국수(소양호 막국수거리, 1.2km), 화천 산천어축제(행사장), 사천진항 물회거리(물회집이 모인 곳)를 고치고, 바뀐 이름은 `alias`에 넣어 다음 점검·사진 매칭에 쓴다. 나머지는 0.6km 안에서 확인됐다. 보헤미안 박이추커피 사천점은 지도 앱 등록 이름이 "보헤미안로스터즈 박이추커피공장"(사천면 해안로 1107)이라 이름을 바꾸고, 좌표는 같은 쪽 번지(해안로 1121·1173, 관광공사)로 추정했다(오차 100~200m). 한국 안의 컴퓨터에서 브이월드로 80곳을 다시 확인해(2026년 11월) 고석정(1.1km, 관광공사 태봉로 1825와 0.13km로 일치)을 고쳤다.
