# 오늘강원

조건 5개만 고르거나 한 줄로 말하면, 영업시간·휴무·이동시간이 맞는 강원도 여행 일정과 숙소를 추천하는 서비스.

## 기존 서비스와 다른 점

| 기존 앱·AI 일정의 문제 | 오늘강원 |
|---|---|
| AI가 없는 장소, 문 닫은 곳, 운영시간 밖 방문을 추천 | AI는 요청을 **조건으로 해석만** 하고, 장소 선택과 시간 계산은 검증된 데이터 기반 엔진이 한다. 충돌 건수를 화면에 표시한다 |
| 입장 마감·브레이크타임 무시 | 계절별 운영시간, 입장·주문 마감, 브레이크타임, 요일별 단축 영업, 매월 휴무일(예: 환선굴 18일), n번째 요일 휴무, 기간 휴장까지 반영 |
| 동선이 비효율적이고 이동시간이 비현실적 | 하루 중심 지역을 먼저 정하고 가까운 순으로 배치. 지도에 실제 도로 경로(OSRM)를 그리고 자동차 이동은 실제 도로 소요시간으로 다시 계산 |
| 축제 정보가 따로 놀음 | 여행 날짜에 열리는 강원 축제를 보여주고, 날짜가 확정된 같은 권역 축제는 일정에 자동으로 넣음 |
| 숙소는 다른 앱에서 따로 | 여행 동선 전체에 맞는 숙소 **한 곳**을 추천해 몇 박이든 짐을 옮기지 않게 하고, 둘째 날부터는 그 숙소에서 출발하도록 일정을 짬 |
| AI가 말만 하고 확인은 안 함 | AI 가이드는 앱 데이터에 있는 장소 id만 고를 수 있고(스키마로 강제), 요청한 변경은 엔진이 영업시간을 다시 확인한 뒤 반영. 못 넣은 곳은 이유와 함께 알려줌 |
| 한 번 만든 일정은 고치기 어려움 | 장소별 `바꾸기`(앞 일정은 유지), 빠른 조정 4개, 한 줄 요청 |
| 입력할 게 많음 | 선택 5개(어디로, 언제, 누구와, 좋아하는 것, 이동). 각 선택지도 5개 이하, 기본값으로 바로 생성 |
| 날씨 반영 없음 | 예보 범위 안이면 비 오는 날을 실내 위주로 자동 변경 |
| 오프라인·내보내기 유료 | 무료로 오프라인 열람(PWA), 링크 공유, 캘린더(.ics), 카카오맵 길찾기 |

## AI 기능 (Claude)

- **한 줄로 시작**: "이번 주말 부모님이랑 속초 1박, 차로" → 5개 선택값을 채우고 바로 일정 생성 (`/api/start`)
- **AI 가이드**: 일정을 보며 묻고 고치기. "비 오면 어떡해?", "2일차에 바다 한 곳 더 넣어줘" → 답변 + 일정 변경 (`/api/guide`)
- AI는 말을 이해하고 설명만 한다. 장소는 검증된 데이터의 id 목록 안에서만 고를 수 있고, 배치와 영업시간 확인은 일정 엔진이 다시 한다
- API 키가 없으면 규칙 기반으로 대신 처리한다 (`public/ai-local.js`)

## 범위

- 권역 5곳: 강릉·동해(삼척 포함), 속초·양양(고성·인제 포함), 춘천·철원(화천 포함), 평창·정선(영월·태백 포함), 원주(횡성 포함)
- 장소 100여 곳, 숙소 지역 26곳, 축제 22개(날짜 확정 3개, 매년 열리지만 올해 날짜 발표 전 19개)
- 2박 이상이면 이웃 권역까지 넓혀 일정을 짠다

## 실행

```bash
cd travel-planner
npm install
ANTHROPIC_API_KEY=sk-ant-... TOUR_API_KEY=공공데이터포털_인증키 npm start
```

`http://localhost:8080` 접속. 키가 없어도 동작한다.
- `ANTHROPIC_API_KEY`: 한 줄 요청 해석 (없으면 규칙 기반 해석)
- `TOUR_API_KEY`: 한국관광공사 TourAPI 공식 사진 (없으면 위키백과·위키미디어 공용 사진)

## 사진

화면은 아래 순서로 장소 사진을 찾는다.
1. `public/photos.json` — 미리 모아 둔 사진 주소
2. `/api/photo` — 서버에 `TOUR_API_KEY`가 있으면 한국관광공사 공식 사진. 이름으로 찾은 결과 중 **좌표가 2km 안에 있는 것만** 써서 이름이 같은 다른 가게 사진이 붙지 않게 한다
3. 위키백과 대표 사진 → 위키미디어 공용 검색

사진을 미리 모아 두려면:

```bash
TOUR_API_KEY=공공데이터포털_인증키 node scripts/bake-photos.mjs
```

## 테스트

```bash
npm test
```

권역·기간·동행·이동수단·취향·요일·계절·속도·날씨의 21,600개 조합에서 영업시간·휴무·입장마감·브레이크타임 충돌 0건, 중복 장소 없음, 시간 겹침 없음, 숙소 추천, `바꾸기` 후 앞 일정 유지, 실제 도로 시간 재계산을 검사한다.

## 구조

```
server.mjs                정적 파일 + AI(/api/start, /api/guide) + 사진(/api/photo)
ai.mjs                    Claude 호출 (한 줄 시작, AI 가이드)
public/ai-local.js        AI 서버가 없을 때 규칙 기반 대체
public/data.js            권역, 장소(운영시간·휴무), 축제, 숙소 지역
public/planner.js         일정 엔진 (점수화 → 지역 선택 → 제약 만족 배치 → 숙소 → 검증)
public/app.js             화면, 지도(OpenStreetMap + OSRM 도로 경로, 내 위치), 날씨, 축제, 숙소, 사진, 공유, 캘린더
scripts/bake-photos.mjs   장소 사진 미리 모으기
```

## 시연 전 확인할 것

- 운영시간은 2026년 11월에 공식 홈페이지·지자체 관광포털·예매처 정보로 확인했다. 출처끼리 다르면 가장 짧은 시간을 썼다. 시장·횟집거리처럼 가게가 모인 곳은 "가게별 상이"로 표시한다.
- 확인하지 못한 곳(뮤지엄 산 관람시간, 월정사, 하조대 등)은 보수적인 시간을 넣었다. 시연 전에 공식 정보로 갱신한다.
- 장소 좌표는 지도 앱으로 한 번 더 맞춰 보는 것이 좋다.
- 바다부채길·해랑전망대(풍랑), 설악산 케이블카(강풍), 삼악산 호수케이블카(2026년 11월 휴장 공지) 등 임시 통제는 시연 직전에 확인한다.
- 날짜가 확정된 축제: 화천 산천어축제(2027.1.9–1.31), 평창송어축제(2026.12.31–2027.2.1), 원주 반계리 은행나무축제(2026.10.30–11.12). 인제빙어축제는 결빙 문제로 3년 연속 취소되어 넣지 않았다.
- 숙소는 특정 업체가 아니라 숙소가 모여 있는 지역과 종류를 추천하고, 네이버·카카오 검색으로 연결한다. 여행 중 조건을 조금 바꿔도 숙소는 그대로 유지된다.
