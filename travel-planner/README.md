# 오늘강릉

조건 몇 개만 고르면 영업시간·휴무·이동시간이 맞는 강릉 여행 일정을 만들어 주는 서비스.

## 기존 서비스와 다른 점

| 기존 앱·AI 일정의 문제 | 오늘강릉 |
|---|---|
| AI가 없는 장소, 문 닫은 곳, 운영시간 밖 방문을 추천 | AI는 요청을 **조건으로 해석만** 하고, 장소 선택과 시간 계산은 검증된 데이터 기반 엔진이 한다. 일정의 모든 장소는 그날 영업 여부를 확인했고, 충돌 건수를 화면에 표시한다 |
| 동선이 비효율적이고 이동시간이 비현실적 | 하루 중심 지역을 먼저 정하고 가까운 순으로 배치. 지도에 실제 도로 경로를 그리고, 자동차 이동은 실제 도로 소요시간(OSRM)으로 일정 시각을 다시 계산 |
| 입장 마감·브레이크타임 무시 | 계절별 운영시간, 입장·주문 마감, 브레이크타임, 요일별 단축 영업까지 반영 |
| 한 번 만든 일정은 고치기 어려움 | 장소별 `바꾸기`(앞 일정은 유지하고 뒤만 다시 계산), 빠른 조정 4개, 한 줄 요청 |
| 입력할 게 많음 | 선택 5개(날짜, 기간, 동행, 취향, 이동수단). 기본값이 있어 바로 생성 가능 |
| 날씨 반영 없음 | 예보 범위 안이면 비 오는 날을 자동으로 실내 위주로 변경 |
| 오프라인·내보내기 유료 | 무료로 오프라인 열람(PWA), 링크 공유, 캘린더(.ics) 저장, 카카오맵 길찾기 |
| 아이·부모님 동반 고려 부족 | 동행에 따라 걷는 양, 체류시간, 장소 적합도 반영 |

## 실행

```bash
cd travel-planner
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

`http://localhost:8080` 접속. API 키가 없어도 동작한다(한 줄 요청은 규칙 기반 해석으로 대체).
`public/` 폴더만 정적 호스팅(GitHub Pages 등)에 올려도 AI 요청 해석을 제외한 모든 기능이 동작한다.

## 테스트

```bash
npm test
```

기간·동행·이동수단·취향·요일·계절·속도·날씨의 4,320개 조합에서 영업시간·휴무·입장마감·브레이크타임 충돌 0건, 중복 장소 없음, 시간 겹침 없음, 점심 포함, `바꾸기` 후에도 앞 일정 유지를 검사한다.

## 구조

```
server.mjs          정적 파일 + /api/adjust (Claude로 자연어 요청 → 조건 JSON)
public/data.js      장소 데이터 (좌표, 운영시간, 휴무일, 체류시간, 실내 여부, 걷는 양)
public/planner.js   일정 엔진 (점수화 → 지역 선택 → 제약 만족 배치 → 검증)
public/app.js       화면, 지도(OpenStreetMap + OSRM 도로 경로, 내 위치), 날씨, 공유, 캘린더
public/sw.js        오프라인 캐시
```

## 시연 전 확인할 것

- `public/data.js`의 운영시간은 2026년 11월에 공식 홈페이지·강릉시 관광포털·예매처 정보로 확인했다. 출처끼리 다를 때는 가장 짧은 시간을 썼다. 커피거리·시장·횟집거리처럼 가게가 모인 곳은 `multi`로 표시해 "가게별 상이"로 보여준다.
- 바다부채길은 풍랑특보 때 통제되고, 오죽헌 실내 전시관은 설·추석 당일 휴관한다. 임시 휴무는 반영되지 않으므로 시연 직전에 한 번 더 확인한다.
- 한국관광공사 TourAPI 등 공공데이터로 자동 갱신하도록 바꾸면 지속 가능성 평가에도 유리하다.
- 사진은 위키백과 대표 이미지를 실시간으로 불러온다. 이미지가 없는 장소는 카테고리 색으로 표시된다.
