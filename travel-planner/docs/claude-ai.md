# Claude AI 켜기 (선택)

보폭은 Claude 없이도 모든 기능이 돌아간다. Claude를 켜면 "말로 일정 만들기"에서 사용자의 말을 더 잘 알아듣는다.
예: "엄마가 무릎이 안 좋아서 계단은 싫어하고, 점심은 앉아서 오래 먹고 싶어요" → 걷기 힘듦 모드 + 메모.

## 역할 나누기
- **Claude**: 말한 문장 → 여행 조건(권역, 날짜, 일수, 동행, 이동수단, 취향, 뺄 것, 이동 편의, 인원, 속도, 출발 시각, 메모)만 뽑는다.
- **일정 엔진(public/planner.js)**: 장소 선택, 운영시간, 동선, 걸음 양, 버스 시간 계산. 지금과 같다.
- 그래서 AI가 없는 장소, 문 닫은 곳, 무장애 정보가 없는 곳을 "가능"이라고 넣을 수 없다.

## 켜는 법
앱 서버(server.mjs)를 배포한 곳의 환경변수에 넣는다. 키는 서버에만 있고 앱·브라우저로 가지 않는다.

| 변수 | 필수 | 기본값 | 뜻 |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | 예 | 없음 | Claude API 키 (console.anthropic.com에서 발급) |
| `CLAUDE_MODEL` | 아니오 | `claude-opus-5-5` | 쓸 모델 |
| `AI_DAILY_PER_IP` | 아니오 | `20` | 한 IP가 하루에 부를 수 있는 횟수 |
| `AI_MONTHLY_USD` | 아니오 | `30` | 한 달 사용 금액 한도(달러). 넘으면 그 달은 자동으로 꺼짐 |
| `AI_ENABLED` | 아니오 | 켜짐 | `0`이면 키가 있어도 끔 |

사용 금액은 데이터 폴더(`APP_DB_PATH`가 있는 폴더)의 `ai-usage.json`에 달마다 센다.

## 꺼지는 경우 (모두 기기 안 해석으로 그대로 진행)
- 키가 없음, `AI_ENABLED=0`
- 이번 달 한도를 넘음, IP 하루 한도를 넘음
- 9초 안에 답이 없음, 오류, 응답 형식이 맞지 않음, 안전 정책으로 거절
- 인터넷이 없음(산간), 서버 없이 쓰는 경우(GitHub Pages·APK 단독)

## 개인정보
- 보내기 전에 전화번호, 카드번호, 주민등록번호, 이메일, 승인번호를 가린다(`maskPII`).
- 영수증·사진·위치는 보내지 않는다. 영수증 글자 읽기는 지금처럼 기기 안에서만 한다.
- 개인정보처리방침(public/privacy.html) 4번 표에 적어 두었다.

## 비용 감
요청 1번은 입력 약 1,500토큰 + 출력 수백 토큰 정도다. 기본 모델(Claude Opus 5.5, 100만 토큰당 입력 4달러·출력 20달러) 기준 대략 1~3센트(약 15~40원)로 예상한다.
실제 값은 켠 뒤 `ai-usage.json`의 `usd ÷ calls`로 확인한다.

## 시험
`node test/claude.test.mjs` — 실제 API를 부르지 않고 개인정보 가리기, 응답 검사, 기기 해석과 합치기, 하루 한도, 키 없을 때 꺼짐을 확인한다.
