# 실시간 버스 켜기 (보폭)

앱은 지금도 버스 **노선·정류장 순서·첫차·막차·배차 간격**(국토교통부 TAGO 버스노선정보)으로 대중교통 일정을 짭니다.
"🚌 16번 6정류장 · 기다림 약 10분"처럼 같은 버스로 가는 구간을 계산하고, 한 번에 가는 버스가 없거나 막차가 지난 동선은 피합니다.

**실시간 도착·버스 위치**는 아래 두 가지가 갖춰지면 켜집니다. 일정의 이동 칸과 "오늘 여행 중"에 **실시간 도착** 버튼이 나옵니다.

## 1. 공공데이터포털 활용신청 (지금 키로는 403 "등록되지 않은 키")

공공데이터포털(data.go.kr)에 로그인 → 아래 세 서비스를 각각 검색해 **활용신청** (보통 바로 자동 승인, 반영까지 1시간쯤)

| 서비스 | 앱에서 쓰는 곳 |
|---|---|
| 국토교통부_(TAGO)_버스도착정보 | 정류장에 몇 번 버스가 몇 분 뒤에 오는지 |
| 국토교통부_(TAGO)_버스위치정보 | 노선의 버스가 지금 어느 정류장에 있는지 |
| 국토교통부_(TAGO)_버스정류소정보 | 정류장 찾기 (나중에 쓸 수 있게 함께 신청) |

키는 지금 쓰는 공공데이터포털 키(TOUR_API_KEY) 그대로입니다. 새 키가 필요 없습니다.

## 2. 앱 서버 배포

실시간 조회는 키가 브라우저·APK에 들어가지 않도록 **앱 서버**(`/api/bus/arrivals`, `/api/bus/locations`)가 대신 합니다.
Render: https://dashboard.render.com → New → Blueprint → 이 저장소 → 환경 변수 `TOUR_API_KEY`에 공공데이터포털 키.

- 같은 정류장·노선은 20초 동안 다시 쓰고, 한 사람당 1분 30번까지만 조회합니다 (하루 호출 한도 보호).
- 신청 전이거나 TAGO가 응답하지 않으면 앱은 "실시간 정보를 받지 못했어요 (시간표 기준으로 보세요)"라고 알립니다.

## 되는 지역

TAGO가 시내버스 자료를 주는 강원 시군: **춘천·원주(횡성 포함)·태백·홍천·철원**.
강릉·속초 등은 TAGO에 없어 실시간·노선 계산이 안 되고, 이동 시간은 거리로 추정합니다 (강릉시 자료 요청 문안: `docs/gangneung-bus-data-request.md`).
