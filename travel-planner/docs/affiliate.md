# 숙소 제휴 링크 켜기

보폭의 숙소 칸(추천 숙소, 무장애가 확인된 숙소, "다른 플랫폼 보기")은 아고다·부킹닷컴 검색으로 연결된다.
제휴를 켜면 이용자가 그 링크로 예약했을 때 운영자에게 수수료가 들어온다. 이용자가 내는 가격은 같다.

## 1. 가입 (운영자가 직접)

### 아고다 — Agoda Partners
- 가입: https://partners.agoda.com (무료, 제휴 약관 동의 필요)
- 소개할 웹사이트 주소가 필요하다. 보폭 웹 주소(GitHub Pages)나 앱 소개 페이지를 적는다.
- 승인되면 관리 화면에서 **사이트 ID(cid, 숫자)**를 확인한다.
- 수수료는 완료된 숙박 기준. 비율은 등급제라 관리 화면의 현재 조건을 확인한다.

### 부킹닷컴 — 제휴 대행사(CJ 또는 Awin)를 통해
- 부킹닷컴은 제휴를 직접 받지 않고 CJ(Commission Junction)나 Awin 같은 제휴 대행사를 통해 받는 것으로 알려져 있다(2025년 이후).
- 대행사에 가입한 뒤 Booking.com 프로그램에 신청한다. 승인되면 **딥링크(감싸는 링크) 주소**를 받는다.
- 가입 화면에서 직접 제휴 번호(aid, 숫자)를 받는 경우도 있다. 받은 것이 숫자면 아래 "번호" 칸에 넣는다.

> 두 회사 모두 조건(수수료, 쿠키 기간, 허용 국가, 앱·소셜 허용 여부)이 바뀔 수 있다. 가입할 때 약관에서 확인한다.
> 정산을 받으려면 세금 정보(개인 또는 사업자)와 계좌가 필요하다.

## 2. 앱에 넣기 — `public/affiliate-config.js` 한 파일만

받은 값을 따옴표 안에 넣고 저장하면 끝이다. 다른 코드는 고치지 않는다.

**GitHub 웹에서 고치는 법**
1. 저장소에서 `travel-planner/public/affiliate-config.js`를 연다
2. 오른쪽 위 연필(✏️)을 누른다
3. 받은 값을 따옴표 안에 넣는다 (예: `agoda: "1891234",`)
4. "Commit changes"를 누른다 → 몇 분 뒤 웹이 새로 배포되고 안드로이드 APK도 새로 만들어진다

```js
export const AFFILIATE_CONFIG = {
  agoda: "",        // 아고다 cid
  booking: "",      // 부킹닷컴 aid
  bookingWrap: "",  // 대행사 딥링크 ({url} 포함)
  agodaWrap: "",
};
```

| 받은 것 | 넣는 곳 | 예 |
|---|---|---|
| 아고다 cid (숫자) | `agoda` | `"1891234"` |
| 부킹닷컴 aid (숫자) | `booking` | `"1234567"` |
| 대행사 딥링크 | `bookingWrap` / `agodaWrap` | `"https://www.awin1.com/cread.php?awinmid=…&awinaffid=…&ued={url}"` |

- 딥링크는 예약 주소가 들어갈 자리를 `{url}`로 바꿔 넣는다. 앱이 그 자리에 숙소·날짜·인원이 담긴 검색 주소를 넣는다.
- https로 시작하지 않거나 `{url}`이 없으면 무시하고 일반 링크로 연결한다(잘못 넣어도 예약 링크가 깨지지 않게).
- 값을 넣으면 숙소 칸에 "제휴 링크예요 · 예약하면 운영자가 수수료를 받을 수 있지만 가격은 같아요"가 자동으로 나온다(추천·광고 표시).

## 3. 효과 보기
앱 서버가 있으면 사용 집계에 `booking_click:booking` / `booking_click:agoda`(어느 사이트를 몇 번 눌렀는지)가 쌓인다. 숙소 이름·날짜·개인정보는 세지 않는다.
실제 예약 건수와 수수료는 아고다·대행사 관리 화면에서 본다.

## 4. 관광지 할인 입장권 (클룩·KKday·마이리얼트립·야놀자 등)

장소 카드의 "🎟 할인 입장권 찾기"는 유료 체험 시설(어른 5천 원 이상, 또는 3천 원 이상인 케이블카·레일바이크·목장·아쿠아리움 등)에만 나온다.

- **지금(설정 비어 있음)**: 네이버 검색 "장소 이름 할인 입장권"으로 열린다. 여러 판매처의 할인가가 함께 보인다. 수수료는 없다.
- **제휴 가입 후**: 각 사이트의 제휴 관리 화면에서 만든 "검색 링크"를 `public/affiliate-config.js`의 `tickets`에 넣는다. 장소 이름이 들어갈 자리를 `{q}`로 바꾼다.

```js
tickets: [
  { name: "클룩", url: "https://(제휴 화면에서 받은 주소)?query={q}&aid=1234" },
  { name: "마이리얼트립", url: "https://(받은 주소){q}" },
],
```

- 넣은 사이트마다 "○○에서 할인 입장권" 버튼이 생기고, 제휴 안내 문구가 자동으로 붙는다.
- https가 아니거나 `{q}`가 없는 줄은 무시하고 네이버 검색으로 둔다.
- 참고(가입 조건은 바뀔 수 있음): 마이리얼트립은 마케팅파트너 가입 후 개인도 바로 쓸 수 있고 판매액의 최대 약 7%를 정산한다고 소개돼 있다. 클룩·KKday도 각자 제휴(어필리에이트) 프로그램이 있다.
